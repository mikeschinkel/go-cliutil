The commands registry reports problems found during Initialize (flag-command registration, validation, building the command tree) as one combined error. Several independent checks can find the same root cause, so the user may see the same problem reported more than once. Initialize should pass the collected errors through a filter before returning them: a built-in step that drops exact duplicates (same sentinel and same metadata), plus an optional app-supplied func([]error) []error for app-specific merging. Nothing needs it yet; file it so it exists when a duplicate shows up.
