go-dt's ErrKV() methods for DirPath, Filepath and EntryPath used to store paths already shortened to ~, by calling ToTilde(), which panics unless the program called dt.EnsureUserHomeDir(). A go-dt task changes them to store the full path, because error-handling code should not generate errors itself. Mike decided that replacing $HOME with ~ is a display concern, belonging in go-cliutil's error printing rather than in doterr or go-dt. cliWriter.Errorf already rewrites each error argument before printing it (newlines become '; '); apps print their final error through it.
