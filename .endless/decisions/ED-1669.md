go-cliutil's built-in global flags live on an embeddable GlobalOptions that implements DefaultOptions (Timeout, Quiet, Verbosity, DryRun, Force). An app's Options type embeds it, declares its own global flags as FlagDefs targeting its fields, and drops or changes built-ins through GlobalOptionsArgs Omit and Overrides; calling an omitted flag's method panics. go-cliutil builds a fresh Options each run from an app OptionsFunc, and handlers get it typed with args.OptionsAs[T](), so every flag value is compile-time checked. This replaces the app-side flag layer (Flags marker, ArgsParser) and go-cliutil's two global flag sets. Mike chose it on 2026-11-17 (go-cliutil E-2544, E-2648). Rejected: Registry Add/Replace/RemoveGlobalFlag with target-less flags read by name; a bare marker Options read through args.Flag.
