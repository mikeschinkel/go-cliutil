go-cliutil pre-loads the global flags almost every app wants (verbosity, quiet, timeout, dry-run, force). An app adjusts them with AddGlobalFlag, ReplaceGlobalFlag and RemoveGlobalFlag, one line each, and parses no flags itself. Global flags have no targets; values reach code through HandleArgs.Flags and an app-supplied OptionsFunc. This removes the app-side flag layer (the Flags marker interface, ArgsParser, apps parsing with Go's flag package) and go-cliutil's two parallel global sets. Mike set three requirements in go-cliutil E-2544 on 2026-11-17: minimal app boilerplate, go-cliutil supplies the common flags, apps override what they want changed. Alternative rejected: keeping a separate app-defined flag tier, which cannot accept global flags after the command words.
