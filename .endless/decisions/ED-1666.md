Handle() becomes Handle(HandleArgs) error, so later additions never change the signature. HandleArgs carries everything a run needs injected (context, StdIO, writer, logger, config, options, the runner) so tests can supply it and one command can call another. Input fields use POSIX names: CommandPath (the command words), CommandLine (everything after the program name), Parameters (everything after the command words), Flags (a type with Get, All, Passed) and Operands (a type of Operand values). Typed flag access is a Go 1.27 generic method, args.Flag[T](name), with no ok result; an undefined name or wrong type panics as a programming error. Mike chose this in go-cliutil E-2544 on 2026-11-17. Alternatives rejected: three separate Handle parameters; the names Argv/Params/Positionals, RawArgs/Parameters/Positionals, or a bare Args, which an LLM misread as the positionals and caused a gomion bug.
