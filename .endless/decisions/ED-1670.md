The app supplies a ConfigFunc that loads its config, so go-cliutil works with go-cfgstore, Viper or anything else; go-cfgstore provides an adapter. Config reaches flag values mainly through ConfigApplier: the app's Options and a command may implement ApplyConfig(Config) and copy values from the config's typed methods into their typed fields, read with cliutil.ConfigAs[T], so every mapping is compile-checked. A name-based Config (such as Viper) may implement FlagValuer instead. go-cliutil applies typed defaults, then config, then the command line, so a typed flag wins.
